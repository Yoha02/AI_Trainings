# Contributing to AI Trainings

Questions, corrections, examples, and code improvements are welcome.

- **Learning or setup question:** use [Q&A](https://github.com/Yoha02/AI_Trainings/discussions/categories/q-a). See [getting help](docs/getting-help.md) for useful context to include.
- **Reproducible bug:** open an issue with the notebook/cell or app step, expected behavior, and a small example.
- **Improvement:** open a focused pull request explaining what a learner will understand or be able to do after the change. Discuss larger changes first so the lessons remain coherent.

For code or notebook changes, run `python -m pytest tests -q` using the environment in the README. Explain what was checked and any limitations. Live Google validation costs money and is optional; do not imply that mocked responses validate live model behavior.

For documentation changes, check that instructions and relative links match the repository. Keep examples based on public or fictional data, and preserve existing contributor credit. Include co-authorship only for people who actually helped author the change.

When sharing help or reviewing a contribution, focus on the example and explain your reasoning. Questions are welcome at every experience level.
